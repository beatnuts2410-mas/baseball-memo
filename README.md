# 野球メモ — Just one more step

## 基準
この版は `野球メモ_v3.01.0_①〜⑤統合テスト版.zip` を基準にした差分修正版。
基準ファイルは別名 `野球メモ_Just_one_more_step_BASELINE.zip` として保存し、以後の作業で戻る基準にする。

## 今回の修正
1. 自チーム／相手チームのユニフォーム画像を、パッケージ内の `nishiharu-uniform.png` / `opponent-uniform.png` から明示的に読み込む構成へ変更。
2. 走者プレー選択画面を画面下寄せから「画面上部開始」に変更。
3. 打者・走者・アウト・得点の選択・確認画面も「画面上部開始」に変更。
4. その他のタップ後オーバーレイ（打席修正、走者修正、アウト修正、守備交代、投手交代等）も同じ定義へ統一。
5. 内容が端末の高さを超える場合は、各画面内で上下スワイプ／縦スクロールできるように変更。
6. 横方向への不要なスクロールはさせない。

## 今回の方針
画面レイアウト、タップ方式、野球記録ロジックは今回変更しない。
今回指定された「表示開始位置」と「縦スクロール」の挙動だけを変更する。
