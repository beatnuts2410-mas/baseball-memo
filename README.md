# 野球メモ v3.03.15

現在の本体 `index.html` は既存版を保持し、更新用の入口として `v30315-latest.html` を追加しています。

## 更新用画面

`v30315-latest.html` は `index.html` を読み込み、v3.03.15 の年度別打者成績表示と共有リンク復元の補正を実行します。

- 年度別打者成績：年度・試合・打席・打数・安打・本塁打・打点・盗塁・打率
- 完了済み試合だけを年度集計
- 盗塁は成功記録のみを加算し、盗塁失敗でも出場試合数は維持
- 共有URLの `m4` / `m5` を親ページ側から復元
- 今後の修正は `v30315-runtime-patch.js` に集約して更新可能

既存の `index.html` はバックアップとして変更していません。
