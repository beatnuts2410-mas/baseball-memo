# ⚾ 野球メモ 本番リリース版 v1.4

高校野球の観戦中に、自チームの攻撃と試合の思い出を「できるだけスマホを見ない」で記録するモバイルPWAです。

## 主な機能
- チーム選手登録
- 試合ごとの1〜9番オーダー
- 前回オーダーのコピー
- DH / 投手登録
- 先攻 / 後攻の選択
- 自チーム攻撃のタップ式打席記録
- 走者 / アウト / 得点 / イニング記録
- 相手攻撃はイニングごとの得点だけ記録
- 代打 / 代走 / 守備交代
- 直前操作の取り消し
- 試合保存 / 過去試合閲覧
- JSONバックアップ
- PWA / ホーム画面アイコン / オフライン起動

## ファイル
- `index.html` — アプリ本体
- `manifest.webmanifest` — PWA設定
- `sw.js` — オフラインキャッシュ
- `icon-192.png` / `icon-512.png` — ホーム画面アイコン
- `DEPLOY_CLOUDFLARE.md` — 本番公開手順
- `RELEASE_NOTES.txt` — リリース内容

## 保存方式
データは端末のブラウザに保存されます。クラウド同期はありません。
大切な試合記録は「データ」→「バックアップ保存」でJSONを保存してください。
