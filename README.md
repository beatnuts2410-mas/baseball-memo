# 西春野球ノート v2.74

GitHub Pages/Cloudflare Pages向け静的Webアプリです。

## 今回の変更
- 試合結果データ共有を「画像共有」中心から「共有URL」方式へ変更。
- 共有URLは試合データを圧縮してURLハッシュに格納し、LINE/SNS等へ送信可能。
- 共有URLを開くと該当試合結果へ直接移動し、受信側のマイアプリへ自動保存。
- 試合結果画面は上部固定せず、全体をスマホで縦スクロールして閲覧。
- 横幅が必要な成績表は横スクロールを維持。
- 共有画像保存機能は「写真として保存」として別に維持。
- 共有結果では自チーム中心、相手投手・相手打者・相手側全記録・エラー表示は除外し、選手交代は保持。

## 共有方式
共有ボタンはQR画像を生成して送るのではなく、`#share=` 形式のデータURLを生成して端末の共有機能へ渡します。CompressionStreamが使える環境ではgzip圧縮してからBase64URL化し、受信側で復元します。
